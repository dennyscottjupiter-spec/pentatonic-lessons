QUICK BRIEFING

  • Pick a ROOT (A–G#), then choose MINOR or MAJOR — each gives you a different set of 5 notes.
  • C + MAJOR: C D E G A — clean, bright, no accidentals. C + MINOR: C Eb F G Bb — darker, bluesier.
  • A + MINOR is the classic rock/blues pentatonic (A C D E G). Start here!
  • 5 box positions cover the whole neck. Press 1–5 on your keyboard to switch fast.
  • Try this: pick A + MINOR, jam Box 1 over a backing track, then hit ▶ START GAME!

🎸 HOW TO USE

  • Pick a ROOT from the 12 key buttons (A–G#). That's your tonal center.
  • Toggle MINOR / MAJOR to switch between that root's minor or major pentatonic — the 5 notes change.
  • Select a BOX POSITION (1–5) to focus on one neck region. Press 1–5 on keyboard.
  • Click any fret to hear it. ROOT notes glow pink, SCALE NOTES glow cyan.
  • ▶ PLAY SCALE plays the box ascending then descending back down.
  • + BLUE NOTE adds the blues note (♭5 in minor, ♭3 in major), drawn with a dashed ring.
  • ♯ / ♭ switches every note name between sharps and flats.
  • PATTERNS: press BUILD and click notes to draw your own shape (numbers = play order), save it by name, or load a classic. Patterns follow the key.
  • The drone button (top left) holds the key's root and fifth so you can hear how each note sounds against it.
  • 🎯 NOTE QUIZ hides the note names and makes one note glow. Name it on the mini piano or type the letter.

🏋️ PRACTICE LAB

⚡ DAILY DRILLS

  • Ascend + descend Box 1 slowly to a metronome click (start at 60 BPM)
  • Play every note in the box, naming it out loud as you go
  • Target the root note on beat 1 — let every phrase land there
  • Connect Box 1 → Box 2 without stopping (overlap frets 7-8)
  • 3-notes-per-string runs across all 6 strings, up and down
  • Practice "call and response" — play a 2-bar phrase, leave 2 bars silence
